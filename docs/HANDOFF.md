# Handoff checklist

The person receiving this site should control:

- the domain registrar account and its renewal payment method;
- the GitHub repository and two-factor authentication recovery codes;
- the GitHub Pages custom-domain setting and the `SITE_URL` repository variable.

Add the original creator as a GitHub collaborator only if ongoing help is wanted. Do not store passwords, recovery codes, or private drafts in this repository: public GitHub Pages requires a public repository on GitHub Free.
